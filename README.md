# Свет Единства

Адаптивный сайт всероссийской мультимедийной акции «СОЗДАЕМ_ВМЕСТЕ», 4 ноября 2026 года. Исходный код и локальные ресурсы находятся в `svet-edinstva/`.

## Запуск

```sh
cd svet-edinstva
node scripts/build-worker.mjs
npm run build
npm run validate
node scripts/check.mjs
```

Подробные инструкции по материалам, дизайну, предпросмотру и публикации: [svet-edinstva/README.md](svet-edinstva/README.md).

В репозитории хранятся сами исходники, без вложенного Git-репозитория. Архивы публикации, локальные данные и ключ доступа к статистике исключены из Git. Для запуска локального предпросмотра нужен локальный ключ `.local/report-password.txt`, как описано в инструкции сайта.
