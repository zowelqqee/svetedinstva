# Свет Единства

Адаптивный сайт всероссийской мультимедийной акции «СОЗДАЕМ_ВМЕСТЕ», 4 ноября 2026 года. Репозиторий готов к импорту в **Vercel из корня**.

## Развёртывание на Vercel

1. В Vercel: Add New → Project → импортировать `zowelqqee/svetedinstva`.
2. Root Directory: корень репозитория (`./`), Framework Preset: **Other**.
3. `vercel.json` уже задаёт Install Command `npm ci`, Build Command `npm run build`, Output Directory `dist` и маршруты API. Ничего дописывать не нужно. Node.js: **22.x**.
4. Нажать Deploy. Страница и материалы работают без секретов.
5. Для статистики: создать **Private Vercel Blob store**, подключить его к проекту. Vercel добавит `BLOB_READ_WRITE_TOKEN`. В Environment Variables добавить длинный случайный `REPORT_PASSWORD` для `/stats`. После добавления переменных сделать Redeploy. Секреты не вводятся в исходный код и не включаются в клиентскую сборку.

Публичность и защита доступа к сайту настраиваются в самом Vercel. Эта конфигурация не создаёт сайт и не меняет аудиторию ранее опубликованной версии в ChatGPT Sites.

Документация: [Node.js Functions](https://vercel.com/docs/functions/runtimes/node-js), [Vercel Blob](https://vercel.com/docs/vercel-blob/using-blob-sdk), [Build settings](https://vercel.com/docs/builds/configure-a-build).

## Структура

```text
api/router.js      # Vercel Function: посещения, отчёт, вход, CSV, скачивание
lib/               # конфигурация, серверная логика и Vercel Blob
src/               # HTML, CSS, JS и config.json — редактируемые исходники
public/            # фотографии, логотипы, шрифт и файлы материалов
scripts/           # статическая сборка и локальный сервер
tests/            # проверки API, авторизации, хранилища и сборки
vercel.json        # сборка, маршруты, защитные заголовки
package.json       # команды и зависимости
package-lock.json  # точные версии для npm ci
.env.example       # имена необходимых переменных, без секретов
```

`dist/` создаётся сборкой и исключён из Git. Изображения и шрифт обслуживаются как обычные статические файлы, без встраивания в JavaScript. Cloudflare Workers/R2 для Vercel не требуются.

## Локальный запуск

```sh
npm ci
npm run build
npm test
npm run dev
```

Открыть http://127.0.0.1:4173. Предпросмотр использует отдельные счётчики в памяти; после перезапуска они обнуляются и не изменяют продакшен-статистику. Ключ для локальной страницы `/stats` автоматически сохраняется в `.local/report-password.txt`, исключённом из Git. Для собственного ключа скопировать `.env.example` в `.env.local` и заполнить `REPORT_PASSWORD`.

## Ожидаемые материалы

Настройки находятся в `src/config.json`. Обновленные правила подключены как `public/rules.pdf`, маска — как `public/materials/mask.pdf`. Оба файла предоставлены 13 октября 2026 года. Почта подключена: `info@svet-edinstva.ru`; обложка — предоставленный файл `oblozhka (1).png`. Пустые значения показывают уведомления.

- Для замены маски обновить `public/materials/mask.pdf` (или указать другой PDF/PNG/ZIP в `maskPath`).
- Положить PDF правил в `public/rules.pdf`; указать `rulesPath: "public/rules.pdf"`. Он откроется отдельно и доступен для скачивания.
- Заполнить `email` реальным адресом.
- Для нового изображения поменять `public/hero.png` или `heroPath`; для логотипа — `cultureLogoPath`.

После коммита в подключённую ветку GitHub Vercel собирает новую версию. Не помещать секреты в `public/` или `src/config.json`: эти данные входят в статический сайт.

## Cloudflare Web Analytics

Предоставленный счетчик подключается при сборке ко всем HTML-страницам: главной, `/stats`, 404 и будущим страницам. Фрагмент хранится в `src/analytics.html`; сборка добавляет его один раз на страницу. В `vercel.json` разрешены загрузка скрипта и отправка beacon-запросов в Cloudflare. Токен счетчика публичный, это не секрет доступа к аккаунту.

Посещения, источники, устройства и показатели загрузки смотрятся в Cloudflare → Web Analytics для домена `svet-edinstva.ru`. В настройках Cloudflare токен должен относиться к этому домену; счетчик не предназначен для другого домена или localhost. После пуша нужен завершенный деплой Vercel. Подключение к коду не подтверждает получение данных в панели Cloudflare.

Cloudflare Web Analytics не поддерживает пользовательские события и не считает скачивания или нажатия кнопок отдельно. Ни в формы, ни в API/PDF/CSV сторонний скрипт не добавляется. Серверный учет скачиваний и отчет `/stats` работают отдельно через Vercel Blob.

Документация: https://developers.cloudflare.com/web-analytics/faq/

## Серверная статистика

`/stats` — отчёт по дням (Москва), CSV, обновление и выход. Вход защищён ключом из `REPORT_PASSWORD`; сессия — подписанная HttpOnly-cookie на один час. События хранятся отдельными объектами с UUID в приватном Vercel Blob, без перезаписи при одновременных обращениях. IP, имена и почта не сохраняются.

Посещение — один сигнал за сессию вкладки; известные боты и автоматизированный браузер исключены. Это визиты по данной методике, не уникальные люди. Скачивание — запрос кнопки с переходом к существующему статическому файлу; сохранение на устройстве неизвестно. Прямые ссылки на файл не увеличивают счётчик. Маска скачивается даже без настроенного хранилища; такие выдачи не попадают в статистику. Без Blob отчёт явно показывает недоступность данных. Старые счётчики версии на ChatGPT Sites остаются в прежнем хранилище и не переносятся автоматически.
