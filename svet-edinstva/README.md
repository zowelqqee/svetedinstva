# Свет Единства — Создаём вместе

Адаптивный сайт по ТЗ на фотографиях. В правках указан срок **27 октября 2026**, он имеет приоритет над 25 октября в исходной визуализации. В меню: Об акции, Правила участия, Контакты. Пять шагов участия. Обещание публикации фотографий в течение недели после акции сохранено; реальных работ пока нет.

## Дизайн и источники

- Официальный брендбук: https://xn--2026-43dlgiaj8a1di1cp.xn--p1ai/brandbook/
- Golos Text: Bold для заголовков, Medium для основного текста. Шрифт хранится локально, лицензия SIL OFL — assets/Golos-OFL.txt.
- Цвета из страницы 19 брендбука: синий #2134A0, красный #DE2726, чёрный #242424.
- Логотип Комитета: официальный архив со страницы https://www.gov.spb.ru/gov/otrasl/c_culture/information/
- Логотип года: оригинальный PNG по ссылке из брендбука.
- В шапке — AI-визуализация проекции, а не фото состоявшегося мероприятия; подпись видна на сайте. Built-in Imagegen. Итоговый промпт: assets/hero-prompt.txt. Изображение: assets/hero.png.
- Папка материалов организатора: https://drive.google.com/drive/folders/1Vpg-64WiyqLi9hk9xQJ0o_Gy5fR1gCC5?usp=sharing (не выведена в публичные контакты).

## Ожидаемые материалы

1. Маска от подрядчика — PDF/PNG/ZIP для скачивания.
2. Финальный PDF подробных правил.
3. Адрес электронной почты для заявок и вопросов.
4. Финальное изображение первого экрана, если нужно заменить визуализацию.

`source/config.json` — единое место подключения. Положить файлы в assets и заполнить maskPath/rulesPath/email/heroPath. Пустые значения показывают понятные уведомления, не запускают ложные скачивания. Правила открываются в отдельной вкладке; средствами просмотра PDF их можно скачать. После замены: `node scripts/build-worker.mjs`, `npm run build`, `npm run validate`, `node scripts/check.mjs`, публикация новой версии того же Site.

## Статистика

`/stats` — отчёт организатора с ключом доступа, CSV и обновлением. События хранятся на сервере в R2, отдельно от локального предпросмотра; не теряются при обновлении кода. Ключ — секрет REPORT_PASSWORD в окружении Sites. Локальная копия для владельца: .local/report-password.txt, исключена из Git.

Посещения: один сигнал на вкладку за текущую сессию браузера, известные боты и автоматизированный браузер исключены. Это количество визитов по данной методике, не уникальные люди. Блокирование JS или сетевые ошибки могут уменьшать число. Часовой пояс Europe/Moscow. Выдачи маски: успешные серверные ответы с реальным файлом; завершение сохранения пользователем неизвестно. При отсутствии маски счётчик не растёт. Персональные данные и IP не сохраняются. События хранятся отдельными объектами с UUID: одновременные обращения не перезаписывают друг друга.

## Разработка

Исходники: source/index.html, source/style.css, source/client.js, source/server.js. Сборщик встраивает изображения и шрифт в worker/index.js. Worker ESM без внешних зависимостей.

`node scripts/build-worker.mjs && npm run build && npm run validate && node scripts/check.mjs`

`node scripts/preview.mjs` — http://127.0.0.1:4173. Локальная статистика в .local/metrics, не продакшен. Запускать только на loopback.
